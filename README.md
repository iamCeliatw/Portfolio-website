# Celia's Portfolio

Next.js 16 + next-intl + Tailwind CSS v4，部署在 Vercel。

```bash
npm ci
npm run dev        # http://localhost:3000
npm run build
npm test           # 內容檔與素材檢查
npm run test:e2e   # Playwright 冒煙測試
npm run shots      # 截圖，需先在 3100 埠跑 npm run start -- -p 3100
npm run lighthouse # Lighthouse 門檻檢查，同上
```
